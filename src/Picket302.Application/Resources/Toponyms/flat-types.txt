# Словари сокращений типов помещений (ТЗ §8.12, функция 148: «Словари топонимов
# и сокращений поставляются файлами, расширяемы»).
#
# Формат: одно понятие в строке; синонимы одного понятия перечисляются через «|».
# Строка, начинающаяся с «#», — комментарий. Секция «[flat]» задаёт категорию
# для следующих строк.
#
# Файл устанавливается пользователем в каталог %APPDATA%\Picket302\Dictionaries;
# понятия из пользовательского каталога дополняют встроенные.
[flat]
кв|квартира
квартира
оф|офис
офис
пом|помещение
помещение
аб|абонентский ящик
абонентский ящик
