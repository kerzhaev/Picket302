# LAY3-01 — воспроизведение до исправления (stage3.2, 2026-11-09)

## Идентификация контрола

Проблемный контрол: **`рядКлипарта`** — `FlowLayoutPanel` (нижняя строка
таблицы переключателей панели «Вид логотипа» главного окна), содержит кнопки
«Клипарт…» и «Убрать логотип».

Цепочка родителей (от формы):

```
MainShell
└─ корень: SplitContainer (Panel1)
   └─ «верх»: TableLayoutPanel (3 колонки 34/34/32 %)
      └─ колонка 2: «панель» (Panel, Dock=Fill)        ← ПостроитьПанельОтображения
         └─ «группаЛоготипа»: GroupBox «Вид логотипа» (Dock=Top, AutoSize)
            └─ «переключатели»: TableLayoutPanel (ColumnCount=1, 5 строк AutoSize)
               ├─ строка 0: Label «Логотип:»
               ├─ строка 1: рядЛоготипа (FlowLayoutPanel: С логотипом / Без логотипа)
               ├─ строка 2: Label «Адрес на конверте:»
               ├─ строка 3: рядАдреса (FlowLayoutPanel: Отправителя / Получателя)
               └─ строка 4: рядКлипарта (FlowLayoutPanel: Клипарт… / Убрать логотип)  ← ПЕРЕПОЛНЕНИЕ
```

## Корневая причина

Конфликт `Dock=Fill` + `AutoSize` в двух местах:

1. **Таблица «переключатели»**: `Dock=Fill` отменяет действие `AutoSize` —
   таблица не могла вырастить родительский GroupBox, высота группы
   фиксировалась по PreferredSize.
2. **PreferredSize таблицы считался по НЕперенесённым высотам** рядов
   (24/24/39 px — FlowLayoutPanel-ряды имели `Dock=Fill + AutoSize`, их
   PreferredSize мерился при ширине, допускающей одну строку). При реальной
   раскладке в узкой колонке ряды переносились (WrapContents) и становились
   48/48/78 px — сумма 232 px превышала зажатую высоту 147 px, и нижняя
   строка уходила за клиент таблицы (GroupBox после первой раскладки
   высоту не пересчитывал).

## Почему увеличение окна — не исправление

Переполнение возникает при любой ширине колонки, при которой ряды
переносятся (узкое окно, 125 %, узкий SplitContainer): размер окна не
устраняет рассогласование «меряем без переноса — раскладываем с переносом».
При 144 DPI дефект скрыт лишь потому, что колонка шире и переноса нет —
уменьшение окна воспроизводит его на любом DPI.

## Почему текущая компоновка неверна

Строка 4 таблицы обязана быть видима целиком: кнопки «Клипарт…» и
«Убрать логотип» — единственный путь назначения логотипа получателю;
их перекрытие нижним содержимым — функциональная, а не только визуальная
поломка (доступность).
