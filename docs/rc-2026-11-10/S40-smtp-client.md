# RC S40 — Встроенный SMTP-клиент: контракт (№100)

Дата: 2026-11-14. Base `d72cc84` (S37-fix). Закрыт разрыв «очередь, отмена,
коды ответов есть; покрытия нет» (S01 строка 100). Критерии: интеграционный
на локальном сервере: очередь, отмена, повтор, timeout, журнал; без внешних
адресатов.

## 1. Тесты (+3, `SmtpClientContractTests`)

| Тест | Критерий |
|---|---|
| `ОтчётПартии_ТочныеСчётчикиИЖурнал` | два получателя — Total=2/Sent=2/Failed=0; журнал отправки (ф.100 `ЖурналОтправки`) — запись на каждого с моментом времени |
| `ОтменаПартии_Токеном_ОтчётСПризнаком` | отмена до отправки → OperationCanceledException из фасада (партия не отправляется, частичный успех не сливается с отменой) |
| `ЧастичныйОтказ_СчётчикиТочны_ОшибкаPersонализирована` | сервер отклоняет RCPT для одного из двух адресов (550) → Sent=1/Failed=1, отказ персонализирован (recipient + текст) |

Стенд: `MimeStand40` — локальный приёмник с отказами на RCPT по признаку
адреса (bad@→550).
