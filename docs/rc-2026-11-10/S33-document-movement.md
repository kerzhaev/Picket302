# RC S33 — Движение документов (№30) + UI входящей корреспонденции

Дата: 2026-11-14. Base `e676e8e` (S32). Функция 30 ТЗ §8.2 + UI-контур
функции 29. Критерии приёмки №30: «валидные переходы, история не
переписывается, текущее местонахождение видно».

## 1. Что реализовано

| Слой | Изменение |
|---|---|
| Домен | `IncomingMovement` (IncomingId → incoming_mails, MovedAt, Action — переиспользует `DocumentMovementAction` Reception/Execution/Archived, Department, Executor) |
| Хранилище | миграция `V010__add_incoming_movements.sql` (FK на incoming_mails, индекс incoming_id+moved_at, `-- Описание:`) |
| Репозиторий | `IIncomingMovementRepository` — **append-only**: только `AddAsync` и `GetByIncomingAsync` (хронологический); Update/Delete отсутствуют на уровне контракта (пин-тест `ПоверхностьРепозитория_ТолькоДополнениеИЧтение`) |
| Служба | `IncomingMovementTracker`: `ПриёмAsync` (первое движение; повтор запрещён), `ПередатьAsync` (требует приёма, запрещён после архива), `АрхивироватьAsync` (завершает цепочку), `ТекущееAsync` (местонахождение + статус), `ИсторияAsync` |
| UI | `FormIncomingMail`: журнал с поиском (номер/отправитель/содержание), колонка «Местонахождение», регистрация (диалог с полями журнала + файл скана), кнопки Приём/Передать…/В архив/История…/Удалить, изоляция ошибок в уведомления; `MainShell`: Сервис → «Входящая корреспонденция…» |
| AppServices | `ТрекерВходящих` |

## 2. Переходы и тесты (+7 трекер, +5 форма)

- Полный цикл приём→передача→передача→архив: история 4 движения, текущее —
  «Архив» (`ПолныйЦикл_…`).
- Текущее местонахождение по мере роста истории («Не принят» → подразделение
  (принят) → (на исполнении)) — `ТекущееМестонахождение_…`.
- Невалидные: повторный приём (`ПовторныйПриём_Запрещён`), передача без
  приёма (`ПередачаБезПриёма_Запрещена`), любое движение после архива
  (`ДвижениеПослеАрхива_Запрещено`), несуществующий документ.
- Append-only закреплён поверхностью репозитория.
- Форма: регистрация через точку автопроверок (выделение новой записи
  программно — ListView без показа формы не наполняет SelectedItems),
  приём/передача/архив через точки, изоляция ошибки движения в уведомление,
  удаление оставляет скан в профиле.
