# RC S47 — Скачивание обновлений с проверкой целостности (№163, остаток)

Дата: 2026-11-14 (редакция: уточнение формулировок по замечанию независимого
ревью). Base `31d8e70`.

**Узкий критерий закрытия этапа:** *скачивание пакета обновления и контроль его
целостности по обязательному SHA-256 из манифеста*. Этап **не** закрывает
установку пакета и **не** закрывает функцию №163 — она остаётся PARTIAL (§6).

## 2. Текущий production-контракт

1. **URL пакета — только HTTPS** (`:204–210`): не-HTTPS отклоняется, загрузчик
   не вызывается. Историческое правило «скачивание по HTTP допустимо при
   наличии хеша» **заменено** корректирующим коммитом `cc9d40c` (2026-11-14).
2. **Обязательный `ExpectedSha256`**: без хеша в манифесте пакет не
   загружается (`:188–193`).
3. **Редиректы запрещены** в обоих HTTP-клиентах (`:410`, `:482`): 30x на
   `http://` отклоняется как ошибка.
4. **Схема адреса манифеста в коде не проверяется** — HTTPS там соглашение из
   документации конструктора (`:79`, `:90`); фактический адрес, заданный
   приложением, — `https://updates.picket302.local/updates.txt`
   (`MainShell.cs:2394`).
5. **Временный каталог**: `%TEMP%/Picket302Update`; в проверках —
   подменяемый `КаталогЗагрузкиДляПроверок` (`:73`), production-каталог
   пользователя проверками не затрагивается.
6. **Возвращается путь к скачанному файлу.** Установка не выполняется,
   файлы приложения не заменяются.

## 3. Манифест без хеша: две разные операции

- **Чтение** манифеста без `sha256` допустимо: `CheckForUpdatesAsync` возвращает
  `ExpectedSha256 = null` при `IsUpdateAvailable = true` (зафиксировано в
  `ОтсутствуетХеш_ЗагрузкаЗапрещена_ЗагрузчикНеВызван`: `Assert.Null(ExpectedSha256)`,
  `Assert.True(IsUpdateAvailable)`).
- **Скачивание** пакета без `ExpectedSha256` запрещено: загрузчик не вызывается
  (`:188–193`, тест `ОтсутствуетХеш_ЗагрузкаЗапрещена_ЗагрузчикНеВызван`).

Эти две операции нельзя смешивать: совместимость чтения манифеста не означает
допустимость загрузки без доказательства целостности.

## 6. Открытый остаток (функция №163 — PARTIAL)

1. **Установка пакета** — не реализована: нет установочных артефактов, нет
   вызова установщика, нет UI-пути.
2. **Криптографическая подпись** (Authenticode/Ed25519) и доверенный канал
   распространения — не реализованы. SHA-256 относительно манифеста
   подтверждает **целостность файла**, но не его происхождение и не подпись.
3. **UI-путь скачивания** отсутствует (легаси-референс содержал кнопку
   «Скачать обновление» в `TUPDATEFORM`).
4. **Решение владельца**: ключ подписания + доверенный канал распространения
   (`FINAL-REPORT-TO-OWNER.md` §7).

## 7. Исторический срез (S47 на момент первоначального коммита `764a458`, 2026-11-13)

Сохраняется как история, **заменено** позднейшим корректирующим коммитом
`cc9d40c` (2026-11-14, «correction pass items 2-3 — update package trust
gates»):

- критерий прежней редакции: «подписанный/повреждённый пакет не ставится;
  откат» (первичного источника этой формулировки в репозитории нет);
- 4 теста, включая `МанифестБезХеша_ОбратнаяСовместимость`;
- §4 прежней редакции: «Скачивание по HTTP допустимо ТОЛЬКО с проверкой хеша
  (иначе отклонить — на усмотрение владельца; сейчас проверка включается
  наличием sha256)».

Что изменилось в `cc9d40c`: production-путь — **только HTTPS** (HTTP
отклоняется), `ExpectedSha256` **обязателен**, редиректы **запрещены**; тест
`МанифестБезХеша_ОбратнаяСовместимость` заменён на
`ОтсутствуетХеш_ЗагрузкаЗапрещена_ЗагрузчикНеВызван` — чтение манифеста без
хеша остаётся возможным, скачивание без хеша запрещено. Историческое правило
«HTTP допустим при наличии хеша» **больше не действует**.
