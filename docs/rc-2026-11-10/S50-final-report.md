## 5. РЕШЕНИЯ ВЛАДЕЛЬЦА (блокируют DONE пяти функций)

1. **№127 клиент-сервер**: OWNER_DECISION=A (SQLite-only, отклонение) /
   B (PostgreSQL, +3–5 волн) / C (гибрид Pro) — документ
   `S41-db-architecture.md`. Затрагивает S42–S45.
2. **№29 сужение объёма** (D-S32-02): хранение связи входящих/сканов в
   отдельной таблице vs mails.incoming_number; встроенный просмотр скана.
3. **№14 probili.ru**: интеграция с внешним сервисом — требуется допустимость
   (DEFERRED; кода в поставке нет).
4. **№163 ключ подписания**: сейчас целостность = SHA-256 манифеста;
   криптоподпись требует инфраструктуры ключей.
5. **Ратификация OVERALL-эрратума** (Волна 2: честный пересчёт 70,31%).
6. **HKCU/HKLM COM-поставки** (S15): пер-пользовательская модель готова,
   машинная — вне ТЗ-запрета отладки.

## 6. Что НЕ вошло / ограничения RC

- S18/S19 (физические принтеры/лотки) — BLOCKED_EXTERNAL.
- COM print happy-path — NOT_RUN_EXTERNAL (интерактивный виртуальный принтер).
- CLEAN_MACHINE — NOT_RUN (процедура готова, нужен контур).
- Предупреждение о ВМ в «О программе» — UI-слой вне юнит-контракта (S46).
- Preview-рендер WYSIWYG — IE-движок; контраст/шрифты не пиксель-пинились.
- Повтор при таймауте SMTP-фасада — проверен косвенно (≥1,5 с); прямой пин
  двух попыток — бэклог.
