# RC S31 — Редактор настроек импорта CSV (№73)

Дата: 2026-11-13. Base `2f3b20d`. Функция 73 ТЗ §8.5 — закрыт разрыв
«покрыто только хранилище профилей; форма без тестов» (S01 строка 89).

## 1. Что сделано

| Критерий приёмки (S01:89) | Закрытие |
|---|---|
| профиль | `Профиль_RoundTripЧерезРеальноеХранилище` — CsvProfileStore (файловый формат `.csvprof`) через штатный адаптер `DelegateCsvProfileStore`, новый диалог применяет загруженный профиль и воспроизводит параметры |
| сопоставление колонок | `СопоставлениеКолонок_ПредложениеИЗакреплениеВПрофиле` — `ImportFieldMapper.Suggest` по именам столбцов, `BuildProfile` закрепляет привязки (Apply сохраняет сопоставленные со слотами) |
| кодировка | `Профиль1251_РеальныйРазборФайлаТочен` — реальные CP1251-байты (0xD4 «Ф»), `Encoding.GetEncoding` с `CodePagesEncodingProvider` (как в продакшн-путях), разбор `DelimitedTextReader` даёт точные значения, 0 ошибок |
| разделитель | «;» и «\t» в тестах; диалоговые комбо; `ConfigureCsvMapping` возвращает профиль ДИАЛОГА (автоопределение — отдельная служба `CsvProfileService.DetectDelimiter`, что зафиксировано тестом) |
| preview | `Предпросмотр_НесовпадениеЧислаСтолбцов_ПомечаетсяКакОшибка` — «ошибочных строк: 1» из «Строк в предпросмотре: 2»; пустой текст — пояснение; доступоры `СведенияПредпросмотраДляПроверок`/`ОшибкаПредпросмотраДляПроверок` |
| ошибки импорта | несовпадение числа столбцов помечается цветом и счётчиком (ТЗ §8.5 ф.73) |
