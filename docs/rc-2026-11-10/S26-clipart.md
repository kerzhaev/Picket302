# RC S26 — Клипарт в произвольном макете blank.xml (№158, остаток)

Дата: 2026-11-12. Base `eea71e6` (Волна 5). Функциональный остаток №158 —
«вставка клипарта в произвольный макет blank.xml» — закрыт полностью:
модель, XSD, сериализатор (round-trip), рендеринг в предпросмотре/печати,
выбор клипарта в редакторе бланков, миграция БД. Продукт: `46794c1`-линия,
коммиты этой волны в git log ниже.

## 1. Что реализовано

| Слой | Изменение |
|---|---|
| Модель (`BlankModel.cs`) | `BlankFieldSpec.ClipartId` (string?) — id элемента библиотеки клипарта; NULL — старое поведение (picture-поле рисует логотип отправителя; совместимость со старыми blank.xml) |
| XSD (`BlankSchema.xsd`) | опциональный атрибут `clipartId` для kind="picture" (XSD-валидация round-trip) |
| Сериализатор | запись/чтение атрибута; отсутствие — совместимо |
| Домен (`Entities/BlankField.cs`) | `ClipartId` — сквозное поле до печатного контекста |
| Рендер (`EnvelopeRenderer`) | picture-поле с `ClipartId` рисует PNG из резолвера (`DrawImageMm` в габаритах поля с offset); не найден → предупреждение; NULL → прежний логотип ( ветка не менялась) |
| Редактор (`FormBlankEditor`) | инструмент «картинка» при размещении открывает `FormClipartPicker`; выбранный id → `поле.ClipartId` |
| AppServices | `КлипартБиблиотека` создаётся один раз; рендереры (печать и предпросмотр) получают резолвер `id → TryGet(id)` |
| БД (миграция V008) | `blank_fields.clipart_id TEXT NULL` + SQL репозитория (INSERT/UPDATE/SELECT через `SELECT *`) |

Отмена: `CancellationToken` срабатывает на каждой странице (границы
`ThrowIfCancellationRequested`); ОК/закрытие до подтверждения не создают
заданий (печать идёт только по явному «Печать» из предпросмотра/диалога).

## 2. Тесты (+3, `ClipartInBlankXmlRoundTripTests`)

1. **RoundTrip_СохраняетClipartId** — сериализация содержит
   `clipartId="конверт"`, десериализация возвращает Picture+id.
2. **СтарыйМакетБезКлипарта_ЧитаетсяБезClipartId** — макет без атрибута
   читается, `ClipartId` = null (совместимость).
3. **RoundTrip_ПустойClipartId_НеПишетАтрибут** — пустой id не сериализуется
   (нет грязных атрибутов).

Все 3 — зелёные; XSD-валидация round-trip проходит (атрибут добавлен в
BlankSchema.xsd, иначе Deserialize бросал BlankXmlException «attribute is
not declared» — найдено и закрыто в этом же этапе).

## 4. Ограничения

- Рендеринг клипарта в предпросмотре/печати — через резолвер PNG
  (`ClipartLibrary.TryGet`); вставка произвольных пользовательских файлов
  (не из библиотеки) — вне функции 158 (библиотека из 10 элементов
  зарегистрирована, файлы пользователя — отдельная функция).
- Совместимость: старые blank.xml (без clipartId) и picture-поля без
  ClipartId ведут себя как раньше (логотип отправителя при WithLogo).
