# RC S28 — Промежуточные данные реестров во временный XML (№58)

Дата: 2026-11-12. Base `1a36917` (S27). Функция 58 ТЗ §8.4
(`Application.Services.ReportDataDumper.DumpReportDataToTempXml`) доведена
до рабочего контура: класс существовал без потребителей и без тестов —
подключён к службе тихой печати, к составу приложения и к меню.

## 1. Что реализовано

| Слой | Изменение |
|---|---|
| `ReportDataDumper` | `LastDumpPath` — путь последнего дампа (null после неудачи/до первого); `DumpReportDataToTempXml` переведён в `virtual` (шов для тестов отказоустойчивости), класс раззапечатан |
| `SilentPrintService` | необязательный параметр `дамперДанных` конструктора; `PrintRegistrySilently` грузит строки запроса реестра ОДИН раз (`ЗагрузитьДанныеРеестраAsync` вместо `ResolveSenderId` — возвращают (sender, rows)), при включённой опции дампит датасет ДО спулинга; ошибка дампа изолирована try/catch — печать продолжается (ТЗ: «переход на генерацию в памяти») |
| Датасет дампа | одна таблица с именем `qrReport_F103` и точными псевдонимами колонок слоя данных (mail_id/out_num/recipient_name/…) |
| AppServices | `ДамперДанныхОтчётов` (опция хранится в таблице parameters) |
| MainShell | Печать → галка «Сохранять промежуточный XML данных реестров» (CheckOnClick), состояние восстанавливается из профиля при старте рядом с опцией «Показывать список шаблонов» (§8.6, ф.82) |

## 2. Тесты (+9)

- `ReportDataDumperTests` (5): структурированный XML (Tables/Table/Row/Field,
  сортировка полей, null → пустой элемент), ветка Payload, ошибка записи →
  null + `LastDumpSucceeded=false` + `LastDumpPath=null`, повторный дамп
  обновляет путь, опция по умолчанию выключена и переживает пересоздание
  дампера (реальный `ParameterRepository` на тестовой SQLite).
- `RegistryReportsTests` (+3): дамп включён — файл создан до спулинга с
  `Table name="qrReport_F103"` и колонками запроса; дамп выключен — файла
  нет; падающий дампер (override с IOException) — печать завершается
  успешно, канал получил документ.
- `MainShellMenuTests` (+1): пункт «Пользовательские отчёты…» (S27) и галка
  дампа (S28) присутствуют в меню «Печать», галка выключена по умолчанию.

## 4. Ограничения

- Дамп подключён к тихой печати реестра ф.103 (путь COM-автоматизации,
  функция 62) — единственный на данный момент контур, строящий реестры из
  слоя данных; интерактивная печать реестров из UI появится вместе с
  соответствующей функцией и получит тот же дампер.
- Ветвь ошибки записи покрыта двумя способами: падение сериализации payload
  (IOException из ToString) и override-дампер; инъекция недоступного
  каталога %TEMP% в тестах не выполняется.
