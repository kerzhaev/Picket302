# RC S29 — Предпросмотр результата в мастере шаблонов документов (№66)

Дата: 2026-11-13. Base `3e9213f`. Функция 66 ТЗ §8.5 — закрыт последний
PARTIAL-разрыв из реестра S01 (строка 66: «preview результата не
реализован»): мастер теперь показывает СФОРМИРОВАННЫЙ документ, а не только
структуру маркеров.

## 1. Что реализовано

| Слой | Изменение |
|---|---|
| `DocTemplateWizardController` | `ПостроитьПредпросмотрРезультата()` — генерация из ТЕКУЩЕГО текста редактора через штатный конвейер: запись во временный файл тем же кодом, что и `Save` (выделен общий хвост `ЗаписатьТекущийТекст`), затем `ArbitraryDocumentEngine.Render`. Text/XSLT → текст результата; OpenXML → описание пакета (N байт). Ошибка генерации → `Success=false` + текст ошибки (ложный результат не изображается); исходный шаблон и состояние контроллера не изменяются; временный файл удаляется в finally |
| `FormDocTemplateWizard` | кнопка «Предпросмотр...» в блоке «Проверка структуры»; `ПостроитьПредпросмотрРезультата()` (публичная, БЕЗ модальных окон — точка автопроверок) и приватный обработчик с диалогом `ФормаПредпросмотраРезультата` (содержимое + предупреждения + заголовок «текущий текст редактора») |

**Найденный и закрытый попутный дефект** (пойман критерием приёмки
«изменение полей обновляет»): первая реализация предпросмотра вызывала
`Save(временный)` — `Save` сбрасывает `IsDirty` и переносит `TemplatePath`
на временный файл, т.е. после предпросмотра мастер «забывал» несохранённые
правки и указывал на удалённый файл. Исправлено выделением
`ЗаписатьТекущийТекст` (запись без побочных эффектов); `Save` и предпросмотр
делят его, состояние контроллера при предпросмотре нетронуто
(тест `ПредпросмотрРезультата_СтроитсяИзТекстаРедактораНеСДиска` фиксирует
`IsDirty=true` и неизменность пути после предпросмотра).

## 2. Критерии приёмки (S01 строка 66) → тесты

| Критерий | Тест |
|---|---|
| preview = то, что будет сохранено | `ПредпросмотрРезультата_СтроитсяИзТекстаРедактораНеСДиска` — правка без сохранения меняет предпросмотр; файл на диске нетронут; `IsDirty` сохраняется |
| изменение полей обновляет | тот же тест: `SetTemplateText` → новый предпросмотр содержит новый документ; плюс `ПредпросмотрРезультата_ПодставляетЗначенияМаркеров` (подстановка значений маркеров) |
| ошибка генерации не сохраняет ложный результат | `ПредпросмотрРезультата_ОшибкаXslt_ЛожныйРезультатНеПоказывается` — битый XSLT → `Success=false`, «Ошибка генерации», без предупреждений-«документа» |
| (гигиена) | `ПредпросмотрРезультата_ИсходныйШаблонНеМеняетсяВременныхФайловНет` — байты шаблона равны до/после, temp-файлов `Picket302_wizard_preview_*` нет |
| (форма) | `ФормаМастера_ПредпросмотрРезультатаБезДиалогов` — публичная точка без модальных окон |

## 4. Ограничения

- OpenXML-пакеты: предпросмотр показывает описание пакета (размер), само
  содержимое .docx не отображается — отображение OpenXML вне функции 66
  (структура маркеров и валидация части word/document.xml доступны как
  раньше).
- Значения маркеров для предпросмотра берутся из переданных в конструктор
  значений (реквизиты выбранного контрагента при вызове из «Сформировать
  документ»); неразрешённые маркеры остаются в тексте и попадают в
  предупреждения.
