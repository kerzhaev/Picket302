# RC S37 — SMTP-прокси (№95)

Дата: 2026-11-13. Base `30cbadd` (S36).
Закрыт разрыв «HTTP CONNECT реализован, тестов нет» (S01 строка 95).
Критерии: маршрут, авторизация, отказ/таймаут; секреты не в логах.

## 1. Локальный стенд (`SmtpProxyStandTests`)

- **SmtpProxyStand**: TcpListener-прокси — читает CONNECT-запрос (полные
  заголовки в `ConnectЗапросы`), при `авторизация` требует
  Proxy-Authorization, при `отказ` отвечает 403, при `молчать` не отвечает
  (таймаут-сценарий); после 200 — реле на минимальный SMTP-сервер.
- Клиент: `SmtpClientFacade` с `ProxySettings{Enabled, Server, Port, Login,
  ProtectedPassword (DPAPI)}`; пароль расшифровывается
  `ProxySettingsMapper` (ЗащищённыйПароль.Расшифровать).
