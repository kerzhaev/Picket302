# RC S39 — WYSIWYG HTML-редактор: контракт (№97)

Дата: 2026-11-14. Base `d72cc84` (S37-fix). Закрыт разрыв «собственный
редактор вместо TinyMCE; тестов нет» (S01 строка 93). Критерии:
«форматирование, сохранение/открытие, очистка опасного HTML, preview;
UI и MIME совпадают».

## 1. Что сделано

| Слой | Изменение |
|---|---|
| Чистый слой | `КомандыРазметки.ОчиститьОпасныйHtml(html)` — НОВОЕ: удаляет блоки script/iframe/object/embed/form целиком, обработчики on*, схемы javascript:/vbscript:/data: (нейтрализация якорем); таймауты Regex от ReDoS |
| Форма | `Загрузить` санитизирует вход — редактор никогда не держит опасную разметку (EditHtml возвращает очищенное) |
| Тесты | +13: 3 форматирования (bold/italic/underline), цвет-hex, списки, экранирование атрибута ссылки (F: `" onmouseover=` разрывает атрибут — экранируется), removeFormat, неизвестная команда, клэмпинг выделения за границами, санитизация (script/iframe/onerror/javascript:+сохранение безопасного), пустая строка, шаблон по умолчанию безопасен, **UI≡MIME** |

## 2. Критерии приёмки → тесты

| Критерий | Тест |
|---|---|
| форматирование | 3 Theory-обёртки + цвет + списки + таблица (КомандыРазметки — чистый слой, без окна) |
| сохранение/открытие | `ЗагрузитьШаблон` (default.html при отсутствии файла) + `ШаблонПоУмолчанию_НеПустойИБезопасный` |
| очистка опасного HTML | `ОчисткаОпасногоHtml_СкриптыИОбработчикиУдаляются` + пустая строка |
| preview | вкладка «HTML-код» → предпросмотр недоступен (сообщение), WYSIWYG-вкладка рендерит `ОбновитьПредпросмотр` — существующее поведение формы, не ломалось |
| UI и MIME совпадают | `РедакторHtml_СовпадаетСMimeПисьмом` — HTML команд редактора → фасад (base64, BodyFormat.Html) → приёмник декодирует байт-в-байт |

## 4. Ограничения

- Санитизатор сохраняет `<img src>` c http(s)/относительными схемами;
  data:-схемы нейтрализуются (вложения писем — отдельный механизм фасада).
- WYSIWYG-вкладка рендерится WebBrowser-контролом в режиме IE — визуальный
  вид (шрифты/отступы) не пиксель-сравнивался; контракт — структура HTML.
