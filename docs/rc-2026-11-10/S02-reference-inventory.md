## 5. Erratum к действующей методике (ревью Q2-2/Q2-3)

Формулировка `02-scoring-methodology.md` «набор из 15 файлов» из CHM и вес
R9=3 в таблице весов остаются в тексте методики без правки истории, однако
с настоящего этапа состав набора классифицируется как **14 иллюстраций
UI + 1 фотография оборудования** (`legacy-print-workflow.jpg`). Фотография
оборудования не является пиксельным референсом программного диалога
(принцип 1 «референс — только реальный»; K1–K6 — критерии UI-сравнения,
к фото неприменимые). R9 возвращается в базу скоринга только при
предоставлении владельцем подлинного снимка UI печатного workflow
легаси-приложения. Матрица S02 §3 — единственная база скоринга для S03/S04;
статусы R9 в исторических `stage5/reference-matrix.md` (PARTIAL) и
`stage5-verify/06-visual-matrix.md` (69 % при W=3 в OVERALL 66,7 %)
противоречат этой классификации и скорингом RC не потребляются.

## 6. Критерий этапа

Выполнен: для каждой пары R1–R9 указан источник с перепроверенным SHA-256,
текущий кадр либо статус NOT_SCORED с причиной; фотография лотка принтера

(локальная CHM-справка + живое окно) и легальность зафиксированы.
