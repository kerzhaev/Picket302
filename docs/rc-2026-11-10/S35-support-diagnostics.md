# RC S35 — Удалённый доступ (№109) + Диагностика сервера БД (№136)

Дата: 2026-11-14. Base `cd96c5e` (S34). Закрыты два PARTIAL-разрыва
(S01 строки 96 и 102), оба «реализация тестопригодна, тестов нет».

## 1. №109 — утилита удалённого доступа

Критерий: «юнит/интеграционный: только https, без реального запуска утилиты».
`RemoteAssistantLauncher` (https-only валидация, внедряемые делегаты
загрузки/запуска, ПоследняяОшибка) уже существовал; добавлены пины:

| Тест | Проверка |
|---|---|
| `HttpАдрес_ОтклоняетсяБезЗагрузкиИЗапуска` | http:// → отказ «должен быть https://» ДО сетевых операций; делегаты выбрасывают при вызове (никакой загрузки/запуска) |
| `НенастроенныйАдрес_ОтказБезЗапуска` | пустая настройка → СообщениеНеНастроено, запуск не выполнялся |
| (существующие) | F-C5 регрессия загрузки: обрыв потока не оставляет частичный файл; успех — целевой файл с данными |

## 2. №136 — диагностика «сервер БД не запускается»

Критерий: «диагностика без непроверенных команд/URL; ошибки показываются
человеку». `DbServiceDoctor` (подменяемый исполнитель sc.exe) и
`FormDbServiceDoctor` существовали; добавлены форм-тесты:

| Тест | Проверка |
|---|---|
| `Диагностика_ОтчётСОшибкамиПоказываетсяЧеловеку` | остановленная служба видна в отчёте формы; выполненные команды — только query/qc подменяемого исполнителя (перечень команд пинится) |
| `УдалитьСлужбу_БезПодтверждения_ОтказБезКоманды` | без подтверждения — отказ, команда delete не выполнялась |
| `УдалитьСлужбу_НераспознанныйВывод_СырыйТекстЧеловеку` | нераспознанный вывод утилиты показан человеку без обрезки |
| точка автопроверок | `FormDbServiceDoctor.ТекстОтчётаДляПроверок` — содержимое поля отчёта |
