# Picket302 — установка клиента на второй компьютер и подключение к общей базе

Инструкция для владельца. Пилот на двух компьютерах **ещё не пройден**: пакет
собран и проверен на сборочной машине, но фактическую установку и сквозной
сценарий на втором компьютере выполняете вы.

Дата сборки пакета: **16.11.2026**. Ветка исходников: `piscine/client-installer-pilot`.

---

## Что вы получите

| | |
|---|---|
| Файл | `picket302-client-setup.exe` (один файл, ~50 МБ) |
| Что ставит | клиентскую программу Picket302 в `C:\Program Files\Picket302` |
| Ярлык | меню «Пуск» → «Picket302» (ярлык на рабочем столе — по желанию) |
| Чего **не** делает | не ставит серверную службу, не открывает порт, не создаёт правило брандмауэра, не меняет сертификаты, не регистрирует COM-сервер автоматически |
| Где данные | `%AppData%\Picket302` — база, настройки сопряжения, секрет устройства, журналы |

Программа **самодостаточна**: установленный .NET на компьютере не нужен.

## Шаг 1. Проверить второй компьютер

1. Windows 11, 64-разрядная (x64). Проверьте: «Параметры» → «Система» → «О
   системе» → «Тип системы». Должно быть **«64-разрядная операционная система,
   x64-процессор»** — то есть именно x64.
   Если там ARM64 — напишите, пакет собран под x64 и на ARM64 пойдёт через
   режим совместимости.
2. Проверьте, установлен ли уже Picket302: «Пуск» → введите `Picket302`.
   Если программа уже есть — **не удаляйте её**. Просто сообщите мне, и я
   подготовлю обновление поверх неё.

## Шаг 2. Сделать резервную копию прежнего профиля (если он есть)

Откройте Проводник, вставьте в адресную строку `%AppData%\Picket302` и
нажмите Enter.

- **Если папки нет** — всё в порядке, переходите к шагу 3.
- **Если папка есть** — скопируйте её целиком (Ctrl+C, затем вставьте в
  отдельную папку, например на рабочий стол) и **проверьте копию**: откройте
  в ней файл `picket302.db` и убедитесь, что он открывается и размер файла
  совпадает с оригиналом.

  **Папку `%AppData%\Picket302` не удаляйте.** Установщик её не трогает: ни
  при установке, ни при обновлении, ни при удалении программы. Резервная
  копия нужна только на случай, если что-то пойдёт не так с вашей стороны.

## Шаг 3. Скопировать установщик и сверить контрольную сумму

1. Скопируйте `picket302-client-setup.exe` на второй компьютер (флешкой или по
   сети — как вам удобно).
2. Ожидаемый SHA-256 пакета указан в файле `LATEST.txt` рядом с собранным
   пакетом в каталоге артефактов
   (`C:\Users\Nachfin\p302-artifacts\client-pilot-20261116\LATEST.txt`) и в
   итоговом отчёте сборки, который я передам вместе с пакетом.
3. На втором компьютере откройте PowerShell и посчитайте сумму файла:

   ```powershell
   Get-FileHash -Algorithm SHA256 -LiteralPath 'C:\Users\<ВЫ>\Downloads\picket302-client-setup.exe'
   ```

   Сравните с ожидаемым значением. **Если суммы различаются — файл перекачан
   не полностью, установку не продолжайте**, скачайте заново.

4. **Не отключайте SmartScreen и антивирус.** Пакет не подписан, поэтому
   Windows покажет предупреждение «Windows защитил ваш компьютер» и «неизвестный
   издатель». Это ожидаемо для неподписанного пакета. Нажмите «Подробнее» →
   «Выполнить в любом случае» — и только после того, как сумма SHA-256
   совпала.

## Шаг 4. Установить и открыть программу

1. Запустите `picket302-client-setup.exe`.
2. Windows спросит разрешение на изменение системы (UAC) — нужно согласие
   администратора: программа ставится в Program Files.
3. Оставьте каталог установки как есть: `C:\Program Files\Picket302`.
4. Отметьте «Создать значок на рабочем столе», если он вам нужен (по
   умолчанию галочка снята).
5. Пункт «Запустить Picket302» в конце — можно оставить включённым. **Если до
   установки уже был профиль** (шаг 2), установщик сам не запустит программу и
   покажет напоминание: сначала проверьте резервную копию, потом открывайте.
6. Нажмите «Готово». Откройте Picket302 из меню «Пуск» обычным двойным
   щелчком.

   **Первый запуск создаёт локальную демо-базу** `%AppData%\Picket302\picket302.db`
   — это штатное поведение: до сопряжения программа работает со своей
   собственной базой. После сопряжения и перезапуска она работает с общей
   базой на сервере, а локальная демо-база остаётся лежать в профиле.

## Шаг 5. Сопрячьте компьютер с общей базой

1. **На серверной машине (192.168.1.42)** откройте PowerShell от
   администратора и выполните:

   ```powershell
   cd <путь к репозиторию>\installer
   .\first-run.ps1
   ```

   Сценарий выдаст **одноразовый код сопряжения**, срок его действия и полный
   отпечаток сертификата сервера:

   ```
     КОД СОПРЯЖЕНИЯ (одноразовый):  XXXX-XXXX-XXXX-XXXX-XXXX-XXXX
     Действует до:                  ... (UTC)

     Отпечаток сервера (показать клиенту для сверки):
     <64 шестнадцатеричных знака>
   ```

   Код действует **10 минут** и используется **один раз**. Если истёк — выдайте
   новый.

   Код и отпечаток **не пересылайте через Git, почту или мессенджер** —
   передайте его лично или по телефону.

2. **На втором компьютере** в Picket302: меню **«Сервис» → «Общая база…»**.
3. Заполните:
   * **Адрес сервера:** `192.168.1.42`
   * **Порт:** `30242`
   * **Код сопряжения:** вставьте полученный на серверной машине код
     (шесть групп по четыре знака, дефисы можно оставить)
   * **Имя этого компьютера:** оставьте как есть или задайте понятное имя
4. Нажмите «Подключить».

   * Программа **сверяет отпечаток сертификата** сервера с тем, что зашит в
     код сопряжения. Если сервер предъявит другой сертификат — сопряжение
     будет отклонено, а не выполнено молча. Проверку сертификата отключить
     нельзя.
   * Сверить отпечаток самостоятельно можно на серверной машине: он напечатан
     скриптом выше; процедура сверки с сертификатом — в
     `installer/README.md`, раздел «Подготовка сертификата».
5. Появится сообщение **«Устройство сопряжено. Изменения применяются при
   перезапуске программы.»** — **перезапустите Picket302** (закройте окно и
   откройте заново).

   После перезапуска программа работает с общей базой на сервере.

   Важно: при недоступности сервера программа **не переходит молча на локальную
   базу**. Она покажет окно «Общая база недоступна» и спросит, продолжать ли
   работу с локальной базой; по умолчанию ответ — «Нет». Общие данные при
   этом не видны и не изменяются.

## Шаг 6. Проверка на обезличенных данных

Выполните на втором компьютере (никаких реальных контрагентов и персональных
данных):

1. **Создание.** Добавьте тестового контрагента (например, «Тест-Иванов
   01.01.1970, тест»).
2. **Видимость на сервере.** Проверьте, что запись появилась:
   * на серверной машине — в данных службы `C:\ProgramData\Picket302\Service`;
   * на первом клиенте (если он открыт) — в списке контрагентов.
3. **Изменение с другой стороны.** Измените запись на другом компьютере
   (например, на первом клиенте или на серверной машине). На втором компьютере
   запись должна обновиться.
4. **Конфликт.** Измените одну и ту же запись на двух компьютерах
   одновременно. Ожидаемое поведение: система сообщает о конфликте и
   предлагает выбор, а не молча затирает чужое изменение.
5. **Обрыв связи.** Разорвите связь с сервером (выключите серверную службу
   **только если вы готовы её потом включить обратно**, или отсоедините
   компьютер от сети). Проверьте, что:
   * программа **сообщает** о недоступности общей базы;
   * программа **не подменяет** общую базу локальной молча;
   * после восстановления связи изменения, сделанные в общей базе, видны.

   Если вы не хотите трогать работающую службу — вместо этого выключите
   сетевой адаптер на втором компьютере на минуту.

## Шаг 7. Печать — отдельным решением

**Физическую печать пока не запускайте.** Сначала нужно отдельно выбрать:
принтер, формат конверта и число тестовых конвертов.

Дополнительно к этому: в комплект поставки **не входит шрифт `ZIPcode.ttf`**
(в репозитории его нет). Пока шрифт не добавлен в комплект, печать
машиночитаемого индекса (кодового штампа) будет блокироваться сообщением
«Не найден шрифт ZIPcode.» (при проверке бланка сообщение звучит как
«Шрифт ZIPcode не найден в системе. Требуется переустановить системные
шрифты из комплекта поставки.»). Обычная печать конверта при этом не
затрагивается.
Сообщите мне, когда решите, добавлять ли шрифт в поставку.

## Что делать, если что-то пошло не так

| Симптом | Что делать |
|---|---|
| Windows ругается на «неизвестного издателя» | Ожидаемо: пакет не подписан. Сверьте SHA-256 (шаг 3) и продолжите |
| Установщик требует прав администратора | Ожидаемо: каталог Program Files. Нужна учётная запись администратора |
| «Общая база недоступна» | Проверьте: служба `Picket302Service` на 192.168.1.42 запущена; порт 30242 открыт; введён правильный адрес |
| «Код сопряжения уже использован» / «Срок действия кода истёк» | Код одноразовый и живёт 10 минут. Выдайте новый на серверной машине |
| Сопряжение не проходит, отпечаток не совпал | Значит, сервер предъявил не тот сертификат. Не обходите проверку: разбирайтесь с сертификатом сервера |
| Порт 30242 недоступен с второго компьютера | Возможна сетевая политика или фильтрация. Проверьте `Test-NetConnection 192.168.1.42 -Port 30242` во втором окне PowerShell |

Журналы программы на втором компьютере: `%AppData%\Picket302\logs\`.

## Как удалить программу (если понадобится)

«Пуск» → «Параметры» → «Приложения» → «Picket302» → «Удалить».

Программа и ярлыки удаляются. **Каталог `%AppData%\Picket302` с базой,
настройками сопряжения и секретом устройства сохраняется** — установщик
сообщает об этом при удалении. Удалять его вручную нужно только если вы
уверены, что Picket302 больше не понадобится.
