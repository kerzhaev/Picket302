База: исходники `b9e2803` (изолированный worktree), прочитаны
`src/Picket302.App/MainShell.cs`, `UI/Forms/*`, `UI/Components/*`,
`Program.cs`, `AppServices.cs`, драйверы `tools/ui-acceptance/*`.
Исторические отчёты использованы только как указатели сценариев.

Компоновка: DI-контейнера нет; composition root — `AppServices`
(миграции SQLite → `SqliteUnitOfWork` → репозитории/сервисы);

сборки — harness `tools/ui-acceptance/Program.cs` (изолированный
профиль, stdin/stdout-протокол: READY, SELECT, SETTAB, F5/F6/F7,
SHOW <ключ>, HIDE, MAILCOUNT, SENTINFO, SEEDFIELDS, SEEDTEMPLATE,

emptybook|printflow|noaddress|screens|screens2|noprinter).

## Выводы по пробелам (для этапов 2/3/6)

1. Вкладки «Конверты» и «Рассылки» никогда не снимались драйверами —
   закрывается собственным драйвером этой сессии (новый файл, без
   правки чужих).
2. Реальный spool из UI-цепочки намеренно не выполняется: оба
   кандидата-принтера имеют интерактивные порты (PORTPROMPT / порт
   PDF-XChange), диалог порта украл бы фокус пользователя. Компенсация:
   app-level spool-проба штатным `SystemDrawingPrintSpooler` с
   PrintToFile (см. 04-print-control.md) + цепочки до диалога печати
   (stage3.9 + перезапуск драйверов этой сессией).
3. Деструктивные формы (Очистка базы, BackupRestore-восстановление,
   USB) — runtime только на изолированных профилях harness.
4. Сироты UI (4 шт.) — в список вопросов владельцу, не удалять без
   решения.
