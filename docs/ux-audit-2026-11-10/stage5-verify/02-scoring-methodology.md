# Stage 5 (verify) — Этап 2: методика оценки визуального сходства (объявлена до оценок)

## Принципы

1. **Референс — только реальный.** В зачёт идут поверхности, для которых
   есть пиксельный референс KonvertProNet происхождением из
   `D:\KonvertProNet\KonvertProNet.chm` (набор из 15 файлов зафиксирован
   с SHA-256 в `stage5/reference/` параллельной сессией; происхождение
   подтверждено hashes/размерами) либо снимок
   `docs/ux-audit-2026-11-03/референс-2026-11-05/01-главное-адресная-книга.png`
   (BitBlt живого окна `TfrmMakeKonvert` 1086×775 — единственный
   референс живого runtime). Поверхности без референса получают статус
   `NOT_SCORED` (структурная проверка отдельна) и в процент не входят —
   это честно ограничивает «охват».
2. **Текущий кадр — только PrintWindow-снимок реального окна**
   Picket302 (b9e2803 + изменения этой сессии), снятый неактивирующим
   harness на изолированном профиле, с фиксацией HWND/PID/размера/DPI.
   Снимки Picket302 никогда не выдаются за снимки KonvertProNet.
3. **CHM-иллюстрации — скриншоты справки низкого разрешения** (296–687 px),
   поэтому сходство оценивается структурно-блочным сравнением, а не
   попиксельным diff. Попиксельный критерий применяется только к паре
   с runtime-референсом главного окна.
4. **Намеренные отличия не штрафуются** (зафиксированы
   `docs/UX-REDESIGN-2026-11-05.md` §3): четыре вкладки и состав меню
   (по ТЗ Picket302), красный/синий акценты отправителя/получателя,
   более светлая палитра `EnvelopeUiTheme`, отсутствие капслока в
   заголовках групп (подтверждено по референсу), хоткеи не в текстах
   кнопок (подтверждено по референсу).
5. Оценка выполняется одним оценщиком (агент) прямым визуальным
   сравнением PNG (Read); для воспроизводимости каждая оценка
   сопровождается именами файлов пары и письменным обоснованием по
   каждому критерию.

## Критерии поверхности (веса внутри поверхности)

| Критерий | Вес | Что сравнивается |
|---|---:|---|
| K1 Топология/структура | 0.30 | состав и расположение блоков (редакторы, таблицы, панели, дерево), их порядок и относительные пропорции |
| K2 Группировка и состав полей | 0.20 | те же группы полей/колонок/секций, их подписи и семантика |
| K3 Типографика и подписи | 0.15 | стиль заголовков (регистр, жирность), состав видимых подписей, хоткеи |
| K4 Контролы и кнопки | 0.15 | набор кнопок/элементов, их форма и размещение, состояния |
| K5 Цвета и палитра | 0.10 | акценты, фон, рамки (с учётом намеренной более светлой палитры) |
| K6 Состояния данных | 0.10 | пустые состояния/длинные значения, если референс их показывает |

Шкала каждого критерия: 0 — отсутствует/полностью иначе; 1 — едва
уловимое сходство; 2 — частично совпадает (меньшинство элементов);
3 — совпадает в основном, отличия второстепенны; 4 — совпадает с
незначительными отличиями; 5 — практически идентично (с учётом п. 4).

Поверхность: `S = Σ(Ki·wi)/5 · 100 %`.

## Веса поверхностей в общем проценте

Веса отражают пользовательскую важность (долю рабочего времени),
объявлены до оценок:

| Поверхность (пара) | Вес |
|---|---:|
| R1 Главное окно / адресная книга | 5 |
| R2 Предпросмотр печати | 3 |
| R9 Печатный workflow (цепочка окон) | 3 |
| R6 Логотип/клипарт | 2 |
| R7 Настройка таблиц | 2 |
| R3 Меню печати и хоткеи | 1 |
| R4 Поиск адреса | 1 |
| R5 Фильтры адресной книги | 1 |
| R8 Архивация/резервное копирование | 1 |

Общий процент: `OVERALL = Σ(Si·Wi)/Σ(Wi)` **только по поверхностям с
референсом**. Поверхности без референса (вкладки «Конверты»/«Рассылки»,
карточка контрагента, большинство диалогов Сервис/Данные) перечисляются
в матрице со статусом `NOT_SCORED (no pixel reference)` и проходят
структурную проверку (существование, отсутствие обрезания, состояние
пустых данных) без процента сходства.

## Границы честности

- `OVERALL_70_PERCENT_MEASURED=true` может быть заявлен только если:
  (а) все 9 взвешенных пар имеют реальный референс и текущий кадр;
  (б) OVERALL ≥ 70; (в) структурные проверки непокрытых поверхностей не
  выявили P0/P1-дефектов.
- Если хотя бы одна пара не снята — статус снижается до PARTIAL с
  явным перечислением недостающего.
- Скоринг одного главного окна (прежние 18/20=90) общим процентом не
  является и в отчёте помечается отдельно.
