# Примеры вызова COM-сервера автоматизации

Документы каталога соответствуют ТЗ §8.9, функция 115 «Примеры вызова из
скрипта и из Excel».

## Состав

| Файл | Назначение |
|------|------------|
| `ExcelCallExample.xls` | Книга Excel с примером вызова `PEPro.Application` из макроса. |
| `ExcelCallExample.bas` | Исходный текст модуля VBA с макросами `PrintEnvelopeFromRegistry`, `PrintEnvelopeSample` и `PrintRegisterToFile`. |
| `../Scripts/printenvelope.js` | Пример вызова из JScript (Windows Script Host). |
| `../Scripts/printregistry.vbs` | Пример печати почтового реестра из XML (VBScript). |

## Порядок использования

1. Зарегистрировать сервер автоматизации:

   ```
   Picket302.ComAutomation.exe --register
   ```

   Регистрация выполняется в ветке пользователя
   `HKCU\Software\Classes`, права администратора не требуются.

2. В Excel нажать `ALT+F11`, затем `File -> Import File...` и выбрать файл
   `ExcelCallExample.bas`. Модуль появится в списке модулей книги.

3. Запустить макрос `PrintEnvelopeFromRegistry` клавишей `F5`.

Макрос `PrintEnvelopeFromRegistry` читает параметры печати из ветки
`HKCU\Software\Picket302\PrintEnvelope` (`FromName`, `FromAddr`, `FromIndex`,
`ToName`, `ToAddr`, `ToIndex`). Отсутствующий параметр даёт пустую строку, а не
исключение, — так же, как и при чтении настроек самим сервером.

4. Макрос `PrintEnvelopeSample` печатает конверт с явно заданными
   параметрами и не требует настроек в реестре.

5. Макрос `PrintRegisterToFile` формирует данные реестра в формате
   `RegistersData` и вызывает `PrintFromXmlRegistersWithoutForm` — печать
   реестра без показа формы с сохранением результата по указанному пути
   (ТЗ §9.1, метод 21). Путь итогового файла задаётся в начале макроса
   (`resultPath`), имя шаблона реестра — там же (`templateName`).

## Кодировка примеров

Файлы `../Scripts/printenvelope.js` и `../Scripts/printregistry.vbs`
сохранены в UTF-16 LE с BOM: Windows Script Host читает такие файлы как
Unicode на любой локали. UTF-8 с BOM для этих файлов непригоден — движок
сценариев читает файл в однобайтовой кодировке, метка порядка байтов
трактуется как символы, и файл не компилируется.

Модуль `ExcelCallExample.bas` сохранён в UTF-8 без BOM. Редактор VBA читает
импортируемый файл в однобайтовой кодировке системы: на русской локали текст
отображается корректно, на иной локали его следует пересохранить в локальной
однобайтовой кодировке (обычное сохранение в «Блокноте»).

## Отсутствие встроенного VBA-проекта

Книга `ExcelCallExample.xls` хранит текст модуля макроса, а сам модуль
поставляется отдельным файлом `ExcelCallExample.bas`, который импортируется
в редактор VBA одним действием (шаг 2 выше).

Встроить скомпилированный VBA-проект в книгу без Microsoft Excel невозможно:
сборка проекта VBA требует средств Microsoft Office, использование которых
запрещено архитектурным требованием ТЗ §8.5, функция 70
(«Полная независимость экспорта от Microsoft Office»). Поэтому макрос
поставляется в виде исходного текста — это единственный способ выполнить
проверку «макрос Excel формирует файл реестра по указанному пути» без
установленного Excel.
